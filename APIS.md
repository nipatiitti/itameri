# API survey for a Baltic Sea web app (browser-only)

Probed 7-8 Oct 2026 with `Origin: http://localhost:5173`. **CORS ✅** = `Access-Control-Allow-Origin`
is `*` or echoes the origin, so `fetch()` works from the browser. **❌** = header missing: download
once with curl and ship static JSON in `static/data` with a source note. Image endpoints (WMS,
WMTS, ArcGIS `export`) work as map layers even without CORS; CORS only matters for `fetch()`.

Build conventions and the MapLibre pattern are in STACK.md; facts and vocabulary in DOMAIN.md.

## Index and the five strongest finds

- Part A: pan-Baltic EU, regional and national services, with a per-country matrix (A8).
- Part B: environment, algae, rivers, nutrient sources, boating, nature, bathing water, litter.
- Part C: maritime culture, museums, wrecks, old charts, JNS's own endpoints.
- Part D: our own Finnish nautical chart tiles, their upstream sources, attribution strings.

1. **HELCOM ArcGIS**: sub-basins, MPAs, eutrophication status, nutrient inputs vs targets, shipping density. Whole sea, open CORS.
2. **Copernicus Marine WMTS without login**: daily chlorophyll, SST, bottom oxygen, ice, with a time dimension.
3. **SYKE**: satellite algae WMS with click-to-value, live citizen bloom reports, river discharge and water quality OData, VEMALA nutrient loads per water body, VELMU species, treatment plants, harbours.
4. **Live gauges from five countries** (FI, SE, DE, PL + Open-Meteo everywhere) for a coherent cross-border view.
5. **Heritage**: 708 registered wrecks from Museovirasto, Finna CC photos, hylyt.net dive data, JNS WordPress REST.

Tonight's pre-download list (no CORS, ship as static JSON with a licence note): EEA discodata
queries you want (E-PRTR water releases for FI, bathing-water time series), Estonian
ilmateenistus observations snapshot, LVĢMC and meteo.lt snapshots if the Baltic-wide gauge map is
the plan, an Overpass extract of pump-out stations if boating is the plan.

## C2. Finna API (best Finnish source)

- Base `https://api.finna.fi/v1/search`, record `…/v1/record?id=`. JSON, no key, **CORS ✅ `*`**.
  Swagger `https://api.finna.fi/swagger-ui/`. 20 records ≈ 21 KB.
- Working example (free-licence sailing-ship photos):
  `https://api.finna.fi/v1/search?lookfor=purjelaiva&filter[]=format:0/Image/&filter[]=~usage_rights_str_mv:usage_A&filter[]=~usage_rights_str_mv:usage_B&field[]=id&field[]=title&field[]=images&field[]=imageRights&field[]=buildings&field[]=year&field[]=geoLocations&field[]=recordPage&limit=20`
- Rights codes `usage_rights_str_mv`: **A = free (CC0/PDM), B = CC BY**, C = CC BY-ND, D = CC BY-NC,
  E = CC BY-NC-ND, F = restricted. `~` prefix ORs filters. `imageRights.copyright` holds the
  literal licence text to display.
- Images: `https://api.finna.fi` + `images[0]` (`&size=small|medium|large`). Hotlinking in `<img>` is
  fine; no CORS on image bytes (no canvas). Record page: `https://finna.fi` + `recordPage`.
- Geo: `geoLocations` is WKT (often a municipality polygon); `rawData.center_coords` = "lon lat".
  Radius search: `filter[]={!geofilt sfield=location_geo pt=60.1,24.9 d=30}` (281 lighthouse
  photos within 30 km of Helsinki).
- Maritime organisations (`filter[]=building:…`): `0/Forum Marinum/` (4 470 records, 2 382 free
  images), `0/RAUMANMERIMUSEO/` (949 CC BY), `0/Kymenlaakson museo/` = Merikeskus Vellamo (2 321
  CC BY), `0/Museovirasto/` (21 682 maritime images CC BY 4.0, many geolocated), Suomen
  merimuseo = `1/Suomen kansallismuseo/Suomen merimuseon esinekokoelma/` (3 219 objects).
- **JNS's own collection is not in Finna or Europeana.**
